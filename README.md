🧮 Calculator App

A beginner-friendly Python calculator that performs basic arithmetic operations.

🧠 About the Project

I built this project to practice Python fundamentals and learn how to create a simple interactive program that accepts user input and performs calculations.

⚙️ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 💻 Interactive terminal interface

🛠️ Technologies

- 🐍 Python
- 💻 Terminal / Command Line

▶️ How to Run

Run the calculator from your terminal:

python calculator.py
